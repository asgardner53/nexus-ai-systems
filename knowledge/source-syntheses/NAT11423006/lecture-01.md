## Source stream
NAT11423006 — Create Custom Artificial Intelligence Assistants, Lecture/Section 1 reading set.

## Reusable concepts identified
1. **AI assistant vs AI agent** — an assistant primarily helps a user perform tasks; an agent may pursue a goal across multiple steps and use tools or connected systems.
2. **Agentic AI** — a broader approach enabling greater autonomy and adaptability within defined boundaries.
3. **Observe → Plan → Act** — a useful conceptual model for how agents gather information, determine steps and perform actions.
4. **Customisation is system design** — role, purpose, instructions, context, tools, permissions, checkpoints and testing matter; a custom assistant is more than a prompt.
5. **Human accountability remains necessary** — greater autonomy does not remove the need for human ownership of consequential decisions.

## Limitations
The source set is predominantly practitioner/vendor material. It is useful for practical orientation but should not be treated as a complete technical taxonomy or independent evidence base for high-materiality claims.

## Five retained takeaways
1. An AI assistant helps with work; an AI agent may carry out parts of the work toward a goal.
2. Agentic AI means greater autonomy, not unlimited authority.
3. Observe → Plan → Act is a useful mental model for agent behaviour.
4. A custom AI assistant is a designed system, not merely a prompt.
5. Humans remain accountable for important decisions.
