# Nexus AI Systems

Central governance repository for Nexus BMG AI Studios, reusable AI systems, operating standards, control records, templates and registers.

> **Public repository:** Do not store student evidence, client-confidential material, personal records, credentials, secret keys or restricted operational data here.

## Governing principle

**AI assists. Humans decide. GitHub records.**

## Authoritative folders

- `governance/` — approved governance and document-control standards
- `studio-control-records/` — approved Studio controls and authority boundaries
- `templates/` — approved reusable control templates
- `registers/` — Studio, document, connector, decision and incident registers
