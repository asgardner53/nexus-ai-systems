# Nexus Studio Build Pack

## Document control

- **Parent standard:** NEX-GOV-003 — Nexus Studio Building Standard
- **Version:** 0.1
- **Status:** Draft
- **Purpose:** Reusable controlled build instrument for applying NEX-GOV-003 to every new or materially changed Studio
- **Repository:** `asgardner53/nexus-ai-systems`
- **Branch:** `studio-building-standard`

## 1. Governing rule

This Build Pack is the execution companion to NEX-GOV-003.

It converts the Standard's required artefacts into one reusable controlled record so that Nexus BMG and other authorised builders can apply the same construction method consistently.

> **The Standard defines the controls. The Build Pack proves they were applied.**

The Pack may be split into linked records for complex Studios, but the required fields and traceability must be preserved.

# Part U — Build Pack control rules

## U1. No blank-by-assumption rule

A required field must not be left blank because the builder assumes it is obvious. Use:

- completed value;
- Not Applicable with rationale;
- Unknown / requires evidence;
- Pending decision; or
- controlled reference to another record.

## U2. Evidence-reference rule

Where a Build Gate is marked Pass, the Build Pack must identify the evidence that supports passage.

## U3. Modular-use rule

Tier 1 or simple Studios may complete this Pack as a single controlled record.

Tier 2–4 Studios may split sections into separate linked artefacts or registers, provided the Build Record preserves complete traceability.

## U4. No-document-proliferation rule

The objective is controlled evidence, not paperwork volume. Builders should avoid creating multiple documents where one structured record can preserve the same control reliably.

## U5. Self-application rule

NEX-GOV-003 itself must be put through this Build Pack before v1.0 approval.

## U6. Build Pack status

This v0.1 Build Pack is Draft and becomes authoritative only when incorporated into and approved with NEX-GOV-003.

## Core rule

> **A Studio cannot claim to have applied the Standard if the evidence of that application cannot be found in its Build Pack or linked controlled records.**
