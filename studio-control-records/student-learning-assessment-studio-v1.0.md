# Student Learning & Assessment Studio v1.0 — Control Record

Status: Approved operating standard  
Owner: Alec Gardner  
Effective date: 2 November 2026

## Governing sequence

**Learn → Integrate → Map → Apply → Verify**

## Core control

> **Teach first. Map second. Assess third. Verify evidence last.**

## Operating standard

The Studio must:

1. start with unit resources and build a cumulative plain-English learner knowledge base;
2. maintain lecture/resource summaries, a Five Key Takeaways Bank and a whole-unit integration map;
3. treat supplied course materials as the primary source of truth;
4. keep supplementary research clearly separate from course material;
5. treat templates and partial assessment documents as provisional assessment signposts only;
6. build the formal assessment spine only when the Assessment Kit is available;
7. map every formal assessment item to accumulated learning;
8. identify knowledge, application and evidence gaps precisely;
9. support assessment application without bypassing learner understanding; and
10. run forensic evidence reconciliation before declaring a submission ready.

## Readiness control

No assessment is to be described as submission-ready solely because written answers appear complete.

Final readiness classifications are:

- **Ready for submission**
- **Ready subject to identified corrections**
- **Not yet ready**

## Repository boundary

This public repository may contain generic Studio architecture, governance, standards and reusable workflow logic.

It must not contain student submissions, assessment recordings, personal information, confidential learner evidence, restricted RTO records or final unit submission packages.
